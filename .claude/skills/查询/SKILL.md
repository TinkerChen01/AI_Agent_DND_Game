# /查询 — 情报检索

## 用法

`/查询 <关键词>`

在游戏数据文件中搜索指定内容。适合查 NPC 背景、地点描述、已获得的情报等。

## 搜索范围

| 文件 | 内容类型 |
|------|---------|
| [L2_模组框架.md](../../../L2_模组框架.md) | NPC 设定、地点描述、势力背景、战斗设计 |
| [L3_人物卡.md](../../../L3_人物卡.md) | 角色背景、能力、关系 |
| [L3b_重要NPC档案.md](../../../L3b_重要NPC档案.md) | 核心 NPC 详细设定 |
| [L4_角色状态.md](../../../L4_角色状态.md) | HP/装备/资源/关系数值 |
| [L5_世界状态.md](../../../L5_世界状态.md) | 当前场景、flag、势力状态 |
| [L6_冒险笔记.md](../../../L6_冒险笔记.md) | 节点记录、已知情报 |

## 流程

1. 在以上文件中搜索关键词（不区分大小写）
2. 汇总匹配结果：
   - 角色/地点/物品的基本信息
   - 与玩家相关的历史事件（来自 L6 节点）
   - 当前状态（来自 L5）
3. 输出简洁摘要（< 300 字）

## 示例

`/查询 格鲁什` → "格鲁什"铁颚"，奥德里克匪帮副官，翠雨月8日在山路伏击战中被兰斯斩杀。持有武器为链枷，身上搜出 25gp 和残信半封。"

`/查询 科恩` → "自称散塔林会编外联系人，在伏击战中投降。提供了三条情报：奥德里克状态、后山密道、低语之刃的来历。约定明日在凡达林旧磨坊交换更多信息。"
