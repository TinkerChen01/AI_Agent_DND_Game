# /检查点 — 状态同步

轻量级状态同步。不生成前情提要，不做 git 提交。

## 流程

### 1. 检查 L4 角色状态
读取 [L4_角色状态.md](../../../L4_角色状态.md)，与当前上下文对比：
- HP、临时 HP、AC
- 法术位 / 狂暴次数 / 咒剑诅咒次数
- 消耗品、金币变化
- 装备、物品获得或失去
- buff / debuff
- 关系表（跨档或浪漫标签变化）

有差异 → 更新对应字段。

### 2. 检查 L5 世界状态
读取 [L5_世界状态.md](../../../L5_世界状态.md)，与当前上下文对比：
- 当前位置、场景描述
- plot_flag 新增或修改
- 游戏内时间推进
- 势力状态变化

有差异 → 更新对应字段。

### 3. 检查 L6 节点遗漏
读取 [L6_冒险笔记.md](../../../L6_冒险笔记.md) 最近节点，回顾当前对话中是否有符合 L0 §4.3 标准但未记录的事件：

| 类别 | 典型事件 |
|------|---------|
| 战斗类 | 遭遇强敌、战胜强敌或非暴力化解冲突|
| 社交类 | 说服/欺骗/威吓关键 NPC、与重要人物关系质变 |
| 探索类 | 发现隐藏地点、解开谜题、获得稀有或魔法物品 |
| 剧情类 | 完成任务/支线、获得关键情报、做出不可逆选择 |

有遗漏 → 按 L6 节点格式追加一条记录。

### 4. 输出确认
- 已同步且有追加节点：`"状态已同步。追加节点：[标题]"`
- 已同步无新增：`"状态已同步，无新增节点。"`
