# dnd-city-rest — 城市休整与随机遭遇

> 适用于玩家主动选择"在城市休息几天"或自由探索期间的轻量化驱动。

---

## 一、城市设施总览

| 设施类型 | 功能 | 说明 |
|---------|------|------|
| 旅店/客栈 | 住宿、简餐、情报集散 | 价格因档次而异 |
| 酒馆 | 饮食、饮酒、娱乐、偶遇 | 冒险者聚集地 |
| 铁匠铺 | 武器/防具买卖、维修、定制 | 大城市可提供精良/魔法装备 |
| 杂货铺 | 冒险用品、工具、口粮 | |
| 市场/集市 | 二手货、农产品、手工艺品 | 可能有意外发现 |
| 裁缝店 | 衣物买卖、定制、缝补 | |
| 魔法商店 | 药水、卷轴、魔法物品 | 仅大城市有，价格昂贵 |
| 神庙/教堂 | 治疗、恢复、祈祷、庇护 | |
| 冒险者公会 | 委托板、认证、同行交流 | |
| 澡堂/浴场 | 清洁、放松、社交 | |

> 不必一次性展示所有设施。玩家询问时才描述，按城市规模自然呈现。

## 二、休整规则

### 触发条件

玩家明确表示"我想在这里休息 X 天"或"我们在城里待几天再出发"时启用。

### 流程

1. 玩家确认休整天数（最少 1 天，建议单次不超过 7 天）
2. 自动计算并扣除休整成本（住宿 + 餐饮）
3. 休整期间，玩家未主动指定行动的天 → 投 d20 决定遭遇
4. 玩家指定了某天行动（如"我今天去铁匠铺"）→ 按正常游戏流程进行
5. 休整结束后，玩家决定下一步去向

### 叙述模式

| 模式 | 操作 | 适合场景 |
|------|------|---------|
| **逐日模式** | DM 每天投骰并实时叙述当天遭遇 | 想沉浸式体验城市生活 |
| **快进模式** | DM 一次性投完所有天数，简要汇总报告 | 想快速跳过休整期 |

### 休整成本

| 档次 | 单人每日费用 | 包含内容 |
|------|------------|---------|
| 简陋 | 2 sp | 通铺床位 + 面包麦粥 |
| 标准 | 5 sp | 单间 + 一日两餐热食 |
| 舒适 | 1 gp | 上好单间 + 三餐 + 热水澡 |
| 奢华 | 2-5 gp | 套房 + 精致餐饮 + 各类服务 |

> 费用自 L4 角色资金中自动扣除。若资金不足，降档或由同伴垫付。

### 叙事鲜活原则

**每天叙述的骨架来自骰子，血肉来自角色互动。** 每天叙述中至少包含一段队友之间的对话或互动（清晨/途中/傍晚/夜间）。
