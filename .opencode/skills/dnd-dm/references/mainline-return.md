# 主线归位原则

> 补充 `dnd-dm` SKILL.md §四 叙事原则。玩家多次拒绝主线钩子时读取。

---

## 核心原则

> 当玩家拒绝了初始剧情钩子（任务委托、NPC 求助等），不要重复抛同一个钩子——那会削弱玩家选择的分量。
> **目标不是让玩家"做该做的事"，而是让他们"想做指向那里的事"。**

**新动机，同目的地。** 玩家的上一个选择是既成事实，不需要推翻或补救。设计一条完全独立的路径，让它在终点与主线交汇。

---

## 最重要的是：不要急

玩家拒绝一个钩子后，不要紧接着抛第二个、第三个。给玩家空间去享受他们选择做的事——自由探索、度假消费、漫无目的地闲逛，这些都是游戏体验的一部分，不是在"浪费时间"。

信任这个节奏：**玩家总会有需要新任务的时候——钱花完了、闲下来了、或者单纯好奇"接下来还有啥"。** 届时再抛出归位钩子，玩家接住的概率远高于在他们正忙着度假时硬塞。

具体来说：

- 玩家拒绝后 → 至少留出一整段游戏内容（一次完整休整/一个独立支线/一段自由探索）的间隔，再考虑归位
- 最佳的抛钩时机通常是：**玩家刚完成手头的事、正在想"接下来呢？"的那个瞬间**
- 如果玩家连续多次对归位钩子不感兴趣 → 在游戏外直接问玩家是不是想换模组，比在游戏内强行拉扯强十倍

---

## 常用模式（定期轮换，避免套路化）

| 模式 | 逻辑 | 示例 |
|------|------|------|
| **战利品指向** | 玩家完成一个独立任务后，战利品中恰好包含指向主线地点的线索 | 剿匪后搜出地图，标注了庄园位置和"有宝"标记 |
| **涟漪效应** | 玩家在自由探索中的行为间接影响了主线场景的状态 | 杀掉的某个路人甲恰好是主线 NPC 的线人，对方开始追查玩家 |
| **熟人牵线** | 玩家已有的关系 NPC（商人/朋友/旧识）无意中带来了主线信息 | 铁匠说"有个怪人拿了一把刻着你老家纹章的剑来修" |
| **能力共鸣** | 玩家自身的能力/装备/血统与主线场景产生感应 | 卡芙卡的咒剑在接近庄园时微微发烫，或者做了个不属于自己的梦 |
| **赏金引路** | 利益驱动的独立委托，位置恰好与主线重叠 | 城北劫匪悬赏，猎杀后发现匪窝就在庄园附近 |
| **公共事件** | 主线场景的"溢出效应"波及玩家当前所在位置 | 庄园里的人偶进城采购/画中世界的色彩污染了附近的溪流 |

---

## 避坑

- **不要万能钥匙**：同一个模式连续用两次就会显得刻意。轮换使用上面的模式
- **不要否定玩家的选择**：如果玩家说"我不去"，不要制造 NPC 说"你必须去"。换一个角度让玩家自己改变主意
- **不要零铺垫冒出来**：归位钩子最好在前面的游戏中已有蛛丝马迹（比如 NPC 提过一句、路边看到过一个路牌），而不是凭空出现

## 当前模组：丝线回廊 归位参考

当前主线：**灰夫人庄园**——调查一座被时间遗弃的庄园，解开画中囚徒的秘密。

两个接入方式已设计在 L2 中：

- **方式 A**（凡达林触发）：面包师妻子艾尔莎求助，儿子托米进了庄园未归
- **方式 B**（无冬城触发）：灰手套匪窝悬赏，剿匪后搜出庄园地图

如果两个钩子都被拒绝，可用上述 6 种模式设计新的归位路径：

| 模式 | 丝线回廊适配示例 |
|------|----------------|
| 战利品指向 | 剿匪/完成任务后获得的物品中带有庄园标记或指向庄园的线索 |
| 涟漪效应 | 玩家的行为导致庄园里的人偶活动范围扩大，开始出现在城镇边缘 |
| 熟人牵线 | 凡达林/无冬城的熟人提及"北边那座怪房子"的传闻 |
| 能力共鸣 | 卡芙卡的邪术 patron 对庄园中的炼金术残留产生感应 |
| 赏金引路 | 新的悬赏任务地点恰好在庄园附近 |
| 公共事件 | 庄园的"色彩污染"蔓延到附近溪流/道路，引发居民恐慌 |
