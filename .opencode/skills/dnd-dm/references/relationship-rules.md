# 关系判定完整规则

> 补充 `dnd-dm` SKILL.md §七 关系判定。关系跨档或浪漫互动时读取。

---

## 1. 五档制

| 等级 | 名称 | 说明 | 典型行为 |
|------|------|------|---------|
| 1 | 死敌 | 你死我活 | 主动陷害、设局、拒绝对话 |
| 2 | 不友善 | 冷淡推诿 | 背后使绊、推脱责任、敷衍 |
| 3 | 中立 | 普通社交距离 | 公事公办、不主动帮忙也不为难 |
| 4 | 友善 | 愿意帮忙 | 分享信息、主动提供便利、维护 |
| 5 | 亲密 | 视你为重要之人 | 牺牲利益、生死与共、深度信任 |

---

## 2. Trend 标记

| 标记 | 含义 |
|------|------|
| ↑ | 在升温（近期互动正面居多） |
| ↓ | 在降温（近期互动负面居多） |
| → | 稳定（无明显偏向） |

### Trend 结算规则

- 同一档内累计 **2 个同向 trend** → 触发跨档
  - 2 个 ↑ → 向上跨一档（如 友善 → 亲密）
  - 2 个 ↓ → 向下跨一档（如 友善 → 中立）
- 跨档时 trend **重置为 →**
- 跨档必须追加 L6 节点（`type: 角色发展`）
- **死敌（1档）和亲密（5档）为边界**，不可再跨

---

## 3. 浪漫标签（仅异性）

| 标签 | 前置条件 | 触发条件 | 显示格式 |
|------|---------|---------|---------|
| **暧昧** | 异性 + 关系深度 ≥ 友善 | 累计 3 次浪漫互动 | `友善（暧昧）` 或 `亲密（暧昧）` |
| **恋人** | 已有暧昧标签 | 累计 3 次更深互动 | `亲密（恋人）` |

### 浪漫互动定义

- 明确的调情/示爱对话
- 肢体亲密接触（牵手、拥抱、亲吻等）
- 为对方做出明显超出普通队友关系的牺牲
- 深情表白或情感独白

### 浪漫标签规则

- 浪漫互动计数器**只增不减**
- 获得或移除浪漫标签 → 必须追加 L6 节点
- 暧昧可在关系降至友善以下时自然消退，但需叙事交代
- 恋人关系破裂是重大剧情事件，需要 L2 支撑

## 4. 判定流程

每次发生可能影响关系的互动时，按以下流程判定：

```
玩家与 NPC 互动
  │
  ▼
这次互动是否包含关系信号？
  │
  ├─ 否 → 不处理，维持当前状态
  │
  └─ 是 → 判断信号方向
      │
      ├─ 正面（帮助、信任、共鸣、浪漫） → trend 记 ↑
      └─ 负面（欺骗、伤害、背叛、冷漠） → trend 记 ↓
      │
      ▼
  检查同档内 trend 累计
      │
      ├─ 同向 < 2 → 维持当前档位
      └─ 同向 ≥ 2 → 触发跨档
          │
          ├─ 向上跨：检查是否满足浪漫标签前置
          │   ├─ 满足 → 评估是否触发暧昧/恋人
          │   └─ 不满足 → 仅跨档
          └─ 向下跨：检查是否触发浪漫标签消退
          │
          ▼
      执行：
        □ 更新 L4 关系表（新档位 + trend 重置为 →）
        □ 追加 L6 节点（type: 角色发展）
        □ 浪漫标签变化时追加 L6 节点
        □ 用自然叙事体现关系变化
```
