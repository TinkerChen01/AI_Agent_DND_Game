# dnd-expand — 模组动态扩展

> 加载 `dnd-dm` 主 Skill 后使用。
> 玩家主动触发的元指令。当玩家感觉到当前方向模组没有覆盖时，AI 检测空缺并动态扩展，扩展结果写回 L2 体系。

**核心原则**：仅扩展空白，不覆盖已有，不剧透，不替玩家做决定。

**主线归位提醒**：玩家偏离主线时，不要重复抛同一个钩子——新动机，同目的地。给玩家空间，等他们闲下来再抛钩。

---

## dnd-expand vs dnd-module-gen 边界

| 判断维度 | 用 dnd-expand | 用 dnd-module-gen |
|---------|--------------|-------------------|
| 空间范围 | 当前模组地图内的空白区域 | 全新的地区/城镇/位面 |
| 叙事范围 | 与当前模组主线有软连接的支线 | 独立的新故事、新反派、新目标 |
| 内容量 | 1-3 个新场景/节点 | 完整的多节点模组结构 |
| NPC | 与现有 NPC 有关联的配角 | 全新的 NPC 阵容 |
| 时间线 | 当前模组时间线内 | 当前模组结束后 |

**灰色地带处理**：如果扩展内容超过 3 个新节点、涉及新地区、且与当前模组主线无直接关联 → 建议玩家先用 dnd-expand 做一个"过渡桥段"（1-2 个场景），然后用 dnd-settle 结算当前模组，再用 dnd-module-gen 生成正式的新模组。

## 触发规则

### 谁触发

**玩家主动触发。** AI 不得自触发。

### 如何触发

玩家使用自然语言即可：
- "扩展一下竞技场"
- "这个地下室模组有写吗？帮我补一下"
- "我想去接个支线任务"
- "帮我扩展一下这个方向"

**注意使用元指令语气（不是游戏内角色对话）。**

## 执行流程

```
1. 读取 L2 §〇 速查索引 → 定位玩家所指区域/节点
   ├─ L2 已有覆盖 → 汇报模组已覆盖，无需操作
   └─ L2 确实空缺 → 读取以下文件锚定上下文：
        ├─ L1_世界设定.md（世界观一致性）
        ├─ L2_模组框架.md（相邻节点风格/难度/基调）
        ├─ L5_世界状态.md（当前 flags/时间/场景）
        └─ L6_冒险笔记.md（已发生事件/已知情报）
        │
        └─ 执行扩展写入（必须遵循模组标准模板格式）：
              ├─ 新节点：按 §二 节点格式（场景描写+互动要素+可搜索物品+完成条件）
              ├─ 新战斗：按 §五 格式（敌人数据+环境+胜利条件）
              ├─ 写入 L2 对应章节（优先）
              ├─ 或另建 L2b_副文件（内容较多时）
              ├─ 更新 L2 §〇 索引表（新增节点/战斗/NPC 行）
              └─ 更新 L6 节点记录（type: 模组扩展）
        └─ 汇报模组已扩展
```

### 文件写入策略

| 内容量 | 写入位置 |
|--------|---------|
| 单个场景/区块（< 50 行） | 追加到 L2 对应章节 |
| 完整支线/大型区域（≥ 50 行） | 新建 `L2b_区域名.md` |
| 新增 NPC/地点/组织 | 追加到 L2 NPC 表或 L1 对应章节 |

---

## 扩展内容约束

1. **风格一致** — 氛围、难度、基调与 L2 邻近节点匹配
2. **世界观一致** — 不与 L1 设定矛盾
3. **不绕过剧情锁** — 不能提供捷径跳过已有的谜题/障碍
4. **与主线有软连接** — 为未来与主线交汇埋下伏笔
5. **不预设玩家行为** — 仅提供"存在什么"，不制造"你必须去"的压力
6. **不剧透 L2 已有设计**
7. **不修改已有的战斗设计和奖励表**

---

## 汇报格式

- 模组已覆盖：`模组已覆盖：这个方向已有现成设计，无需扩展，直接继续即可。`
- 模组已扩展：`模组已扩展：已补充相关框架，保持了一致性，可以继续。`

两种汇报均不带叙事语气、不扮演任何角色、不暗示玩家"该做什么"。
