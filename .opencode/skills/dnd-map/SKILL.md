# dnd-map — 战术地图系统

> 用 ASCII 符号生成可视地图，帮助玩家理解空间关系。
> 地图渲染由 `scripts/render_map.py` 执行，AI 构造 JSON 数据后调用。

---

## 何时展示地图

| 场景 | 自动展示 |
|------|---------|
| 战斗初始化 | 是（必须） |
| 战斗中每回合 | 是（更新位置） |
| 进入新区域（首次探索，空间结构已知） | 是 |
| 玩家问"周围有什么" / "位置" | 是 |
| 战斗中距离/位置有疑问 | 是 |
| 普通对话/叙事 | 否 |
| 空间结构未知（首次进入未知区域） | 否（等探索后补绘） |

## 地图类型

### 1. 战斗地图（combat）

用于战斗场景，展示所有参战者位置、地形、物品。

**数据格式：**

```json
{
  "title": "战斗标题",
  "round": 1,
  "grid_width": 12,
  "grid_height": 8,
  "terrain": [
    {"x": 0, "y": 0, "w": 3, "h": 8, "symbol": "#", "label": "墙壁"},
    {"x": 5, "y": 3, "symbol": "*", "label": "壁炉"}
  ],
  "entities": [
    {"symbol": "@", "name": "兰斯", "x": 2, "y": 3, "hp": "45/45", "side": "player"},
    {"symbol": "K", "name": "卡芙卡", "x": 2, "y": 5, "hp": "31/31", "side": "player"},
    {"symbol": "E", "name": "人偶A", "x": 7, "y": 2, "hp": "18/25", "side": "enemy"}
  ],
  "items": [
    {"symbol": "○", "name": "掉落物", "x": 5, "y": 6}
  ],
  "legend": ["*=壁炉(光源)", "○=掉落物"]
}
```

**调用方式：**

```bash
python scripts/render_map.py --type combat --data '上述JSON'
```

### 2. 楼层总览（floorplan）

用于展示多层建筑的探索进度。

```json
{
  "title": "灰夫人庄园",
  "floors": [
    {"id": "3F", "name": "画室", "status": "current", "rooms": ["画室"]},
    {"id": "2F", "name": "书房", "status": "explored", "rooms": ["主卧", "书房"]},
    {"id": "1F", "name": "门厅", "status": "explored", "rooms": ["门厅", "走廊"]},
    {"id": "B1", "name": "地下", "status": "locked", "rooms": ["实验室(封印)"]}
  ],
  "connections": [["3F","2F"], ["2F","1F"], ["1F","B1"]]
}
```

### 3. 区域探索（explore）

用于展示城镇、荒野等大尺度的区域关系。

```json
{
  "title": "无冬城",
  "areas": [
    {"name": "渡鸦之羽旅店", "status": "explored", "notes": "已住 7 天"},
    {"name": "矮人回火", "status": "explored", "notes": "铁匠布隆"},
    {"name": "市场广场", "status": "current", "notes": "当前位置"}
  ],
  "paths": [["渡鸦之羽旅店","市场广场"], ["市场广场","矮人回火"]]
}
```

## 符号图例

完整符号说明见 `references/map-symbols.md`。常用符号速查：

| 符号 | 含义 |
|------|------|
| @ | 兰斯（玩家） |
| K | 卡芙卡（队友） |
| E | 敌人（用 E1/E2 区分） |
| N | 中立 NPC |
| # | 墙壁/不可通行 |
| . | 可通行地面 |
| = | 门（关闭） |
| * | 火源/光源 |
| ○ | 物品/战利品 |
| △ | 陷阱 |
| ~ | 水域/危险地形 |
| ? | 未知/迷雾 |

## 战斗中的地图流程

1. **战斗初始化**（`dnd-combat` 触发时）：构造战斗场景的 JSON 数据 → 调用 `render_map.py` → 将地图嵌入 L4b 底部或叙事输出中
2. **每回合更新**：更新实体坐标 → 重新渲染 → 输出更新后的地图
3. **战斗结束**：地图随 L4b 一起清空

---

## 与 dnd-combat 的集成

`dnd-combat` 初始化战斗时，应在输出中包含初始战斗地图。回合中实体移动后更新地图坐标并重新渲染。

## 地图数据来源

> **Token 优化**：优先从 L2 §〇 速查索引定位地区和节点，再精确读取对应段落。不要全文读取 L2。

| 场景 | 数据来源 |
|------|---------|
| 战斗 | L2 §〇 战斗索引表定位 → §五 战斗设计（环境描述+combat JSON） + L5（当前位置） |
| 建筑楼层 | L2 §〇 地区表定位 → §二 地区详设（floorplan JSON） + 探索过程中积累的信息 |
| 城镇区域 | L5 当前位置 + L6 已探索记录 |
| 野外 | L2 §二 地区详设（空间布局 ASCII 图） + AI 构造 |
