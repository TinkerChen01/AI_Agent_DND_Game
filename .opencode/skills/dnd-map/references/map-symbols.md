# 地图符号图例

> dnd-map Skill 的完整符号规范。

---

## 基础符号

| 符号 | 含义 | 使用场景 |
|------|------|---------|
| `@` | 玩家角色（兰斯） | 战斗/探索地图 |
| `K` | 卡芙卡（队友 NPC） | 战斗/探索地图 |
| `E` | 敌人（通用） | 战斗地图，可用 E1/E2/E3 区分 |
| `N` | 中立 NPC | 探索地图 |
| `.` | 可通行地面 | 战斗地图 |
| `#` | 墙壁/不可通行 | 战斗地图 |
| `~` | 水域/危险地形 | 战斗地图 |
| `^` | 高处/台阶 | 战斗地图 |
| `=` | 门（关闭） | 战斗地图 |
| `▯` | 门（打开） | 战斗地图 |
| `□` | 箱子/家具/障碍物 | 战斗地图 |
| `△` | 陷阱/危险标记 | 战斗地图 |
| `○` | 物品/战利品 | 战斗地图 |
| `*` | 火源/光源 | 战斗地图 |
| `?` | 未知区域/迷雾 | 战斗/探索地图 |

---

## 标注规则

### 角色名标注

在符号后直接追加名字（无空格），用于地图下方信息栏：

```
@兰斯(HP:45/45)  K卡芙卡(HP:31/31)  E1人偶A(HP:18/25)  E2人偶B(HP:25/25)
```

### 距离标注

在实体信息栏中标注关键距离（每格 5 ft）：

```
@→E1: 15ft  K→E2: 20ft  @→K: 10ft
```

### 方向标注

使用 N/S/E/W 或 ↑↓→← 标注朝向或移动方向。

### 高度层

多层地图用不同行区块分隔，标注楼层标签：

```
[3F] 画室 ← 当前
       │ 楼梯
[2F] 书房 ✓ 已探索
       │ 楼梯
[1F] 门厅 ✓ 已探索
```

---

## 状态符号

| 符号 | 含义 | 用于 |
|------|------|------|
| `★` | 当前位置 | 楼层总览/区域地图 |
| `✓` | 已探索 | 楼层总览/区域地图 |
| `🔒` | 封锁/未解锁 | 楼层总览 |
| `?` | 未知 | 楼层总览/区域地图 |
| `—` | 未探索 | 区域地图 |

---

## 网格尺寸指南

| 场景类型 | 建议宽度 | 建议高度 |
|---------|---------|---------|
| 小房间（书房/卧室） | 8-10 | 6-8 |
| 中房间（门厅/大厅） | 12-16 | 8-12 |
| 大场景（庭院/野外） | 16-24 | 12-16 |
| 走廊/窄道 | 4-6 | 12-20 |

---

## 地图边界

- 地图四角使用 ╔╗╚╝
- 水平线使用 ═
- 垂直线使用 ║
- 标题栏和信息栏之间使用 ╠╣
- 地图内容区与边框之间留一格空白
