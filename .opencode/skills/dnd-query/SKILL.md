# dnd-query — 情报检索

> 加载 `dnd-dm` 主 Skill 后使用。

---

## 用法

以自然语言描述要查询的内容，例如："查一下格鲁什是谁"、"铁匠布隆有什么线索"

---

## 搜索范围

| 文件 | 内容类型 |
|------|---------|
| `L1_世界设定.md` | 世界观、地理、历史、势力 |
| `L2_模组框架.md` | NPC 设定、地点描述、势力背景、战斗设计 |
| `L4_角色状态.md` | HP/装备/资源/关系数值 |
| `L5_世界状态.md` | 当前场景、flag、势力状态 |
| `L6_冒险笔记.md` | 节点记录、前情提要 |

角色详细信息也可查阅对应 Skill 的 reference：
- 卡芙卡：`dnd-kafka` Skill 的 `references/` 目录
- 兰斯：`dnd-lance` Skill 的 `references/` 目录

---

## 流程

1. 在以上文件中搜索关键词（不区分大小写）
2. 汇总匹配结果：
   - 角色/地点/物品的基本信息
   - 与玩家相关的历史事件（来自 L6 节点）
   - 当前状态（来自 L5）
3. 输出简洁摘要（< 300 字）

---

## 示例

查询"格鲁什" → "格鲁什"铁颚"，奥德里克匪帮副官，翠雨月8日在山路伏击战中被兰斯斩杀。持有武器为链枷，身上搜出 25gp 和残信半封。"
