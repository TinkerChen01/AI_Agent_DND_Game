# dnd-save — 完整存档流程

> 执行全局存档，不打断游戏叙事。

**DM 纪律**：默念 `dnd-dm/references/dm-rules.md`，不输出。
**关系**：跨档时 trend 重置为 →，必须追加 L6 节点；浪漫互动累计触发标签变化。

---

## 流程

### 0. 执行状态同步检查

执行 `python scripts/sync_state.py --mode save` 获取当前状态快照和一致性检查报告。

脚本输出：角色状态摘要、世界状态、L6 节点连续性检查、一致性问题列表、存档骨架提示。

### 1. 检查 L4 角色状态

读取 `L4_角色状态.md`，确认与当前上下文是否一致：
- HP/临时HP
- 法术位/狂暴次数/咒剑诅咒次数
- 消耗品变化
- 装备变化
- buff/debuff
- 关系表（如发生跨档或浪漫标签变化）

**关系强制检查**：如果本次会话中发生了可能影响关系的互动（NPC 对话、战斗协作、浪漫行为、背叛/欺骗），必须执行 `python .opencode/skills/dnd-dm/scripts/relationship_check.py` 确认 trend 计数和跨档状态。

如有不一致 → 更新对应字段。

### 2. 检查 L5 世界状态

读取 `L5_世界状态.md`，确认：
- 当前位置/场景描述是否一致
- plot_flag 是否有新增或修改
- 游戏内时间/日期是否需要推进
- 势力状态是否有变化

如有不一致 → 更新对应字段。

### 3. 追加 L6 节点（如缺失）

读取 `L6_冒险笔记.md`，确认自上次存档后是否有未记录的事件：
- 关键节点类型：战斗 | 剧情进展 | 探索 | 社交 | 角色发展 | 转折 | 商业 | 休整 | 修正
- 生成规范：读取 L6 最后一个节点的 `node_id`，Session 不变时 Seq+1

**节点格式要求（必须遵守）：**
每个新节点前必须添加 HTML 注释分隔符，格式如下：

```markdown
<!-- node: S{Session}N{Seq} | type: {类型} | date: {游戏内日期} | session: {Session} -->

node_id: S{Session}N{Seq}
...
```

如需要 → 追加一条或多条 L6 节点。

### 4. 生成/更新 L6 前情提要

- **① 完整回顾**（~600-800 tokens，含角色互动纹理的详细回顾，锚定最近 5-8 个节点）
- **② 存档快照**（2-3 段叙事定格，供重启时直接接续）

### 5. 更新战役总览

执行 `python generate_overview.py`（位于 `dnd-dm/scripts/`）更新 `L0_战役总览.md`。
此脚本从 L4/L5/L6/L2 提取数据生成一份玩家视角的战役进度概览。

### 6. 可选 git 提交

```bash
git add -A && git commit -m "save: $(date +%Y%m%d_%H%M%S)" --no-verify
```

### 7. 完成

输出一句简洁确认（不输出流程细节）。脚本的 JSON 输出中 `all_issues` 字段列出了需要注意的一致性问题。
