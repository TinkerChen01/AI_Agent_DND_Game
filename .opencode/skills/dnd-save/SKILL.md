# dnd-save — 完整存档流程

> 执行全局存档，不打断游戏叙事。

**DM 纪律刷新：**
- 不替玩家做决定，不建议"你应该"
- NPC 动机来自 L2，不自由发挥
- 基于状态叙事（角色在 A 地就不描写 B 地）
- 不输出文件读写等元信息到叙事中
- **关系**：跨档时 trend 重置为 →，必须追加 L6 节点；浪漫互动累计触发标签变化

---

## 流程

### 1. 检查 L4 角色状态

读取 `L4_角色状态.md`，确认与当前上下文是否一致：
- HP/临时HP
- 法术位/狂暴次数/咒剑诅咒次数
- 消耗品变化
- 装备变化
- buff/debuff
- 关系表（如发生跨档或浪漫标签变化）

如有不一致 → 更新对应字段。

### 2. 检查 L5 世界状态

读取 `L5_世界状态.md`，确认：
- 当前位置/场景描述是否一致
- plot_flag 是否有新增或修改
- 游戏内时间/日期是否需要推进
- 势力状态是否有变化

如有不一致 → 更新对应字段。

### 3. 追加 L6 节点（如缺失）

读取 `L6_冒险笔记.md`，确认自上次存档后是否有未记录的事件：
- 关键节点类型：战斗 | 剧情进展 | 探索 | 社交 | 角色发展 | 转折 | 商业 | 休整 | 修正
- 生成规范：读取 L6 最后一个节点的 `node_id`，Session 不变时 Seq+1

如需要 → 追加一条或多条 L6 节点。

### 4. 生成/更新 L6 前情提要

- **① 叙事摘要**（~200 tokens，第一人称，口语化）
- **② 前情提要**（~600-800 tokens，完整回顾，锚定最近 5-8 个节点）
- **③ 存档快照**（2-3 段叙事定格，供重启时直接接续）

### 5. 可选 git 提交

```bash
git add -A
git commit -m "checkpoint: 游戏存档" --allow-empty-message --no-verify
```

### 6. 完成

输出一句简洁确认（不输出流程细节）。
