# AI Agent DND Game — 兰斯的冒险

一套以 AI Agent 为核心设计的 D&D 5e 单人跑团游戏框架。AI 同时担任 DM（地下城主）和队友 NPC，玩家只需扮演自己的角色，通过自然语言对话来推进冒险。

## 这是什么？

想象你坐在桌前，对面是一个永远有空的 DM。你说"我拔出巨剑，走向那扇铁门"，DM 就给你描述门后是什么。区别在于——这个 DM 是一个 AI Agent，它通过读取项目中的一套结构化数据文件（称为 L0-L6）来记住世界观、模组剧情、角色状态和冒险历史，并依据 `.opencode/skills/` 中的一套行为规则来主持游戏。

不需要安装任何游戏引擎。你只需要一个支持 Agent Skill 的 AI 编程工具（当前使用 OpenCode），打开这个项目目录，说一句话就能开始。

## 快速开始

### 前提条件

- 安装了 [OpenCode](https://opencode.ai)（或兼容的 Agent 编程工具）
- Python 3.10+（项目中的辅助脚本需要）

### 启动游戏

```bash
# 1. 在 OpenCode 中打开项目目录
cd /path/to/AI_Agent_DND_Game
opencode

# 2. 在对话框中输入：
游戏继续
```

AI 会自动加载 `dnd-dm` Skill（DM 行为总纲），读取 L0-L6 数据文件，合成战役梗概，然后从上次存档的场景接续叙事。

### 如果是全新的冒险（无存档）

AI 会读取 L1（世界观）、L2（模组框架），从头开始一段新故事。当前模组是「丝线回廊」——一座被遗弃三十年的庄园，和一个把自己关进画里的炼金术师。

## 玩家指令速查

游戏过程中，你只需要用自然语言说话。以下是 AI 能识别的关键指令：

| 你说的话 | 触发效果 |
|---------|---------|
| `游戏继续` / 直接以角色行动开场 | 启动或继续游戏 |
| `游戏暂停` | 切回助手模式（讨论规则/架构） |
| `存档` / `保存` | 完整存档（同步所有状态文件 + 生成前情提要） |
| `检查点` / `检查一下` | 轻量状态同步（不生成前情提要） |
| `查询 XXX` / `查一下 XXX` | 跨文件检索信息（如"查一下格鲁什"） |
| `战斗开始` / `先攻` | 初始化战斗（投先攻、生成战斗日志） |
| `地图` / `看看周围` | 显示 ASCII 战术地图 |
| `扩展` / `补充模组` | 在模组空白处动态扩展内容 |
| `休整` / `休息几天` | 城市休整（触发 d20 随机遭遇） |
| `新模组` / `下一个冒险` | 生成全新模组 |

日常游戏中你不需要记住这些指令——正常说话就行。"我走进书房"会自动触发场景切换，"卡芙卡你怎么看"会自动加载她的角色 Skill。

### 数据文件分层

| 文件 | 性质 | 更新频率 | 说明 |
|------|------|---------|------|
| L0 | 自动生成 | 每次存档 | 脚本从其他文件聚合的战役概览 |
| L1 | 静态 | 极少改动 | 世界设定，游戏基石 |
| L2 | 半静态 | 跨模组时 | 当前模组的完整设计 |
| L4 | 动态 | 战斗/休整/获得物品 | 角色的实时数据，唯一写入点 |
| L4b | 临时 | 战斗期间 | 战斗结束后归档并清空 |
| L5 | 动态 | 场景切换/flag 变化 | 世界的实时状态 |
| L6 | 追加 | 关键事件/存档 | 冒险的结构化记忆 |

### Skill 体系

每个 Skill 是一个目录，包含三个可选子目录：

- **SKILL.md** — AI 的行为指令（核心规则，常驻或少量注入）
- **references/** — 详细数据文档（按需查阅，不常驻上下文）
- **scripts/** — 可执行 Python 脚本（不消耗 token，100% 确定性执行）

Skill 通过关键词自动触发。比如提到"卡芙卡"就自动加载她的性格锚点和说话风格，说"存档"就执行完整存档流程。

## 当前角色

**兰斯**（玩家扮演）— 人类野蛮人（狂战士）Lv.4。STR 20，手持 +1 精良巨剑。直觉型冒险者，信奉"强就是正义"。

**卡芙卡**（AI 扮演）— 半精灵邪术士（咒剑士）Lv.4。CHA 19，从不高声说话，用反问句回应一切，半真半假是她的艺术。兰斯的搭档和……嗯，她自己也不会承认的那种关系。

## 游戏机制要点

**检定** — 默认 AI 代掷。AI 会报 DC 和技能类型，掷骰并播报结果，然后基于结果叙事。如果你想自己投骰，说"我自己掷"即可。

**战斗** — 分完整战斗（Boss/主线，完整回合制 + L4b 战斗日志 + 战术地图）和快速战斗（小遭遇，AI 叙述为主，几次关键检定决定结果）。

**关系系统** — 5 档制（死敌→不友善→中立→友善→亲密），附带 trend 标记和浪漫标签。你和 NPC 的每次互动都可能影响关系走向。

**存档** — 说"存档"触发完整流程：同步 L4/L5/L6、生成前情提要、更新 L0。AI 也会在战斗结束、场景切换、关系变化后主动建议存档。
