# dnd-战斗开始 — 战斗初始化

加载 `dnd-dm` 主 Skill 后使用。

## 流程

### 1. 读取参战者数据

- 玩家方：读取 `L4_角色状态.md` 获取 HP/AC/属性
- 敌方：读取 `L2_模组框架.md` 获取战斗设计数据（敌人属性）

### 2. 写入 L4b

覆盖写入 `L4b_战斗日志.md`，填充：
- 战斗概况（名称、时间、地点、先攻顺序、回合数）
- 参战者速查（角色、阵营、HP、最大HP、AC、状态）
- 资源消耗（角色、资源类型、初始值、消耗、剩余）

### 3. 投先攻

- 玩家方先攻：询问玩家是否自投，否则代掷
- 敌方先攻：DM 代掷
- 排序后填入 L4b「先攻顺序」

### 4. 输出

- 当前场景描写（2-3句）
- 先攻顺序列表
- 提示当前回合行动者

> 战斗中状态变化仅维护在上下文。超过 10 回合时每 3 回合刷新一次 L4b 快照。
> 关键转折点（倒地/boss入场/环境剧变）追加到 L4b「关键转折点」。
